### Introduction
This repository contains scripts used to train a transformer-based model for diagnostics of antimicrobial resistance in clinical infections.

### Dependencies
To run the scripts in this repository, the following software is required:
- Python >= 3.11.3
    - PyTorch >= 2.1.2
    - Transformers >= 4.39.3
    - Pandas >= 2.3.2
    - Numpy >= 2.3.3
    - Scikit-learn >= 1.3.1
